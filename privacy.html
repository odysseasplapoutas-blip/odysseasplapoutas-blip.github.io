Privacy policy

V2 is a private tool used only by its owner.

With the owner's permission, V2 uses Google's Gmail API with a single permission: to send email from the owner's own Gmail account. It uses this only to send automated system notifications to the owner's own email addresses.

V2 does not read, store or search any mailbox through this permission, and it does not collect, sell or share personal data with anyone. The permission can be withdrawn at any time in the owner's Google Account settings (Security › Third-party access).

V2's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the owner's GitHub account, github.com/odysseasplapoutas-blip.
